# Section 6 Worksheet — Domain Foundation

## 1. Your domain sketch (after 6.1)
The records your agent protects, each record's owner and lifecycle,
and the audit event each change should emit. Mark the read-only line.

## 2. One record with rules inside (after 6.2)
Write a record with at least one constructor invariant and one state
method that refuses an illegal transition. Add a two-record seed that
gives every ownership test a foreign record.

## 3. Content owners (after 6.3)
List the content sources your assistant answers from. Assign an
accountable owner to each. Sources without one are homework.

## 4. Your event list (after 6.4)
The decisions an auditor could ask about, the event each should emit
(actor, action, target, outcome), and every field you struck because
it would carry untrusted content.

## 5. Three read verbs (after 6.5)
Your first three read verbs over your domain: actor-scoped, one audit
event per outcome, refusal recorded before it is thrown.

## Recap self-test (after 6.6)
Rebuild the map: three records, three verbs, one trail. List the write
verbs you will eventually need with the decision, rule, and test each
requires.
